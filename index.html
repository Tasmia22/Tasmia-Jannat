Research

Systems research at the intersection of architecture, algorithms, and data.

My work explores how emerging memory-centric and accelerator architectures can improve the performance and efficiency of irregular, data-intensive workloads.

01

Processing-in-Memory

Parallel algorithms and workload placement for commercial UPMEM PIM systems, including spatial and graph workloads.

02

GPU-Accelerated Computing

Memory-conscious GPU designs for spatial search, polygon processing, and high-throughput geometric workloads.

03

Scalable Data Analytics

High-performance methods for spatial indexing, graph traversal, and scientific or engineering datasets.

04

Memory-Efficient LLM Inference

Emerging research interest in memory behavior and systems support for efficient large-language-model inference.

Selected Projects

Research systems built for real hardware.

Selected work spanning PIM, GPU, CPU multithreading, spatial indexing, and graph processing.

01
UPMEM PIMR-treeISC 2026

PIM-based R-tree on UPMEM DPUs

Designed and implemented an R-tree-based spatial query system on commercial UPMEM PIM DPUs for parallel batched query processing.

15.23× kernel speedup 16M rectangles 3.99M queries
02
UPMEM PIMGraph Processing

BFS-FAR: PIM-based Graph Processing

Designed BFS-FAR for breadth-first search on UPMEM PIM, reducing synchronization and host–DPU communication overhead across large DPU deployments.

03
CUDASpatial Query

GPU R-tree Query System

Implemented GPU-accelerated range queries using a flattened BFS layout and per-thread DFS traversal with pruning, reaching about 65× speedup over CPU on an 8.4M-rectangle workload.

04
C++MultithreadingR-tree

CPU Multithreaded R-tree

Built a parallel R-tree search framework using STR construction, a persistent thread pool, and cache-aware traversal.

Spatial ComputingR-tree

Multithreaded Polygon Intersection
